Данные для формирования документов

Поля на этой странице используются при автоматической генерации запросов в государственные органы и банки (формат Word). Если данные не заполнены — документы будут сформированы с пустыми полями.

Для физического лица обязательны:

  • ИНН, СНИЛС, дата рождения;
  • место рождения (регион и город);
  • адрес прописки;
  • счета в банках (номер счёта и банк).

{# ========================================================= 1. Как открыть карточку ========================================================= #}

1 Как открыть карточку должника

  1. В верхнем меню нажмите Выберите должника из списка.
  2. В выпадающем списке выберите нужного должника — отобразится ФИО и номер дела.
  3. Откроется форма редактирования. Все изменения применяются только после нажатия кнопки «Сохранить».
{# ========================================================= 2. Основные данные ========================================================= #}

2 Основные данные

Блок «Основные данные»
Поле Обязательно Пояснение
Тип должника Да Физлицо или юрлицо. От этого зависит набор обязательных полей: например, для юрлица скрываются СНИЛС, дата и место рождения.
ФИО / Наименование Да Для физлица — полное ФИО одной строкой, для юрлица — официальное наименование как в ЕГРЮЛ.
ИНН Да* 10 цифр для юрлица, 12 — для физлица. * Для юрлица обязателен, для физлица — желателен.
СНИЛС Желательно 11 цифр. Только для физлиц.
Дата рождения Желательно Формат ДД.ММ.ГГГГ (выбирается календарём). Только для физлиц.
Поля с отметкой Да не сохранятся, если оставить их пустыми — форма выдаст ошибку и подсветит проблемное поле.
{# ========================================================= 3. Место рождения ========================================================= #}

3 Место рождения только для физлиц

Блок доступен только для типа «Физлицо». Есть два режима — переключаются кнопками в шапке блока.

«Выбрать существующий»

Вы выбираете регион из уже заведённого списка. Если у должника ранее был указан регион рождения — он автоматически подсветится в выпадающем списке, а над ним появится подсказка «Сейчас: …».

«Создать новый»

Вы вводите название региона (можно оставить пустым) и город (обязательно). Новый регион будет добавлен в общий справочник и станет доступен другим должникам.

При режиме «Создать новый» поле «Город» обязательно. Если город не указать — форма вернёт ошибку и не сохранит изменения.
{# ========================================================= 4. Адрес прописки ========================================================= #}

4 Адрес прописки

Аналогично месту рождения, блок работает в двух режимах. Текущий адрес отображается подсказкой «Сейчас: …» над выпадающим списком.

В выпадающем списке отображаются адреса в формате:
Регион, город, улица, д. N, стр. M, кв. K
Выберите нужный адрес. Если ранее у должника была указана прописка — она подсветится автоматически.

Поле Обязательно
Регион Нет
Город Да
Улица Да
Дом Да
Корпус / строение Нет
Квартира Нет
Поле «Корпус / строение» — только текст. Если у дома нет корпуса, оставьте поле пустым, а не пишите «нет» или «-».
{# ========================================================= 5. Счета в банках ========================================================= #}

5 Счета в банках

В блоке перечислены все счета должника. Каждая строка — один счёт: его номер и банк, в котором он открыт.

Добавить счёт

  1. Нажмите кнопку + Добавить счёт в шапке блока — появится новая строка.
  2. Введите номер счёта (до 20 цифр).
  3. Выберите банк из выпадающего списка.

Если нужного банка нет в списке

В выпадающем списке выберите вариант + Добавить новый банк — под строкой счёта раскроется блок для ввода реквизитов банка.

Поле нового банка Обязательно Пояснение
Название банка Да Например: ПАО Сбербанк. Будет добавлен в справочник банков.
Почтовый индекс Желательно 6 цифр. Используется в шапке запроса в банк.
Регион Нет Если региона нет — оставьте пустым.
Город Да Город, где находится отделение банка.
Улица Нет Без слова «улица».
Дом Нет Номер дома.
Корпус Нет Номер корпуса/строения, если есть.

Удалить счёт

Нажмите × справа от строки. Строка уберётся со страницы; чтобы удаление вступило в силу, не забудьте нажать «Сохранить» внизу страницы.

Один и тот же банк можно указывать для нескольких счетов — вводить его повторно не нужно, он уже будет в выпадающем списке.
{# ========================================================= 6. Сохранение и ошибки ========================================================= #}

6 Сохранение и обработка ошибок

Все изменения вступают в силу только после нажатия кнопки «Сохранить». Если форма содержит ошибки — страница вернётся с подсвеченными проблемными полями и списком сообщений.

Типичные ошибки

Сообщение Что делать
Счёт #N: выберите банк В строке счёта с номером N выберите банк из списка или создайте новый.
Счёт #N: укажите номер счёта Заполните поле «№ счёта» в строке N.
Для нового банка «…» нужно указать адрес: город, улица, дом Раскройте блок нового банка и заполните обязательные поля.
Для должника «…» не указан город В блоке «Место рождения» выберите режим «Создать новый» и заполните город.
Название банка обязательно Укажите название нового банка в соответствующем поле.
{# ========================================================= 7. FAQ ========================================================= #}

7 Частые вопросы

Скорее всего, форма не была сохранена. Новые банки, регионы и адреса сохраняются в справочники вместе с должником — если закрыть страницу без нажатия «Сохранить», они не будут созданы.

При выборе варианта «— не указан —» адрес прописки будет очищен при сохранении. Чтобы сохранить старый адрес — не трогайте выпадающий список. Текущий адрес всегда отображается подсказкой «Сейчас: …» над списком.

Эти поля относятся только к физлицам и автоматически скрываются, если в поле «Тип должника» выбрано «Юрлицо».

Для физлица — да, но без ИНН часть запросов может не сформироваться. Для юрлица ИНН обязателен: без него генерация документов невозможна.

Нажмите красную кнопку × справа от строки счёта, затем — «Сохранить». Строка исчезнет вместе с сохранением формы.
